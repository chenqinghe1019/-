# 下方了：高级抽具体英雄明细报表口径（2026-08-27）

该报表与“14档高级抽区间报表”不是同一份 SQL，不能混用区间。

本报表特点：
- 高级抽限定 `gacha_type=2`。
- 输出需要拆到具体英雄维度，字段包含：抽卡阶段、英雄类型、英雄、英雄产出数量、人均产出数量、平均多少抽产出1张、阶段内英雄数量占比、阶段实际抽数、阶段玩家数、抽到该英雄玩家数。
- 本报表原有抽数阶段保持：
  - 350抽以前（累计抽数 < 350）
  - 750-3499抽（累计抽数 >= 750 且 < 3500）
  - 3500-8499抽（累计抽数 >= 3500 且 < 8500）
- 不自动替换成当天另一份高级抽分析使用的14档区间，除非用户明确要求修改这份具体英雄明细报表的区间。
- 历史累计高级抽数使用 `recruit_log` 顶层 `gacha_num`；`award_ting` 仅拆奖励。
- 传说+实际英雄名使用 `天使神加百列`、`妖狐妲己`，不再使用旧名 `天师加百列`、`狐妖妲己`。
