# 下方了：流失名单归类分析（2026-08-13）

## 口径

- 样本：新增首日充值 >= 500 元角色，共 63 人。
- 已流失 37 人，未流失 26 人。
- `是否滚服=是` 的 SQL 含义：当前角色的 `nb_open_id` 下存在创建时间更早的其他角色，即“玩家创建当前角色前已经有老角色经历”。
- `是否滚服` 是玩家来源/经验标签，不表示当前角色流失后又去了其他服。
- 当前 SQL 未额外限制 `old_role.region_id <> cr.region_id`，严格语义为“同 nb_open_id 存在更早角色”；若业务允许同服多角色，需补服务器不同条件。
- 本次只保存聚合结果，不保存玩家 ID / 昵称明细。

## 推荐的 5 类流失归类

1. **D1-D2 首充试水流失：10人**
   - 其中滚服仅1人，样本不足以做滚服/非滚服比较。
   - 首5日充值中位约834元，充值天数中位1天，主线几乎没有继续推进。
   - 更像首充后快速判断“不继续玩”。

2. **D3-D4 滚服早退：6人**
   - 在 D3-D4 流失组占 60%。
   - 和同批 D3-D4 非滚服流失玩家相比，原始成长表现并不差：历史累充中位1175元，前期战力增幅约181%，主线推进23.5，海岛推进22.5，战力排名恶化约1.5名。
   - 但与“同为滚服且未流失”的玩家比较到相同 D3/D4 时点，差距明显：累计充值约为对照中位的79%，战力约32%，主线约31%，累计灵签约76%，排名约差2名。
   - 说明这类不是“完全不会玩”，而是相对滚服玩家应有的高效率成长明显掉队/停滞。
   - 多名玩家在最后活跃日前1-2天已经停止充值，且最后活跃日部分主线/海岛不再推进，存在“先减投/减玩，再退出”的迹象。

3. **D3-D4 非滚服成长/竞争受挫：4人**
   - 与同为非滚服且未流失玩家比较到相同 D3/D4：累计充值约60%，战力约44%，主线约78%，海岛约75%，战力排名约多恶化4名。
   - 这类的核心不是完全没推进，而是“付费投入减弱 + 战力/榜单竞争落后”更明显。
   - 优先查 D2-D4 的战力卡点、资源消耗、榜单竞争和付费停止前后的行为。

4. **D7+ 滚服高强度流失：3人**
   - 这3人前5日表现非常强：首5日充值中位3410元、充值5天、战力增长约1693%、主线推进77、海岛推进72、排名反而提升1名。
   - 相比同为滚服且未流失玩家，前5日充值还高约1284元，成长和推进也更快。
   - 因此前5日完全看不出“早期体验失败”，真正掉点一定发生在 D5 后。
   - 这类价值最高，应直接接“最后活跃日前1~3日行为”模型追玩法覆盖、在线、PVP、BOSS、押镖、充值停止和成长停滞。

5. **D7+ 非滚服渐进衰减：14人**
   - 相比未流失非滚服玩家，首5日充值中位低约612元；战力增长约513% vs 964%；主线推进45 vs 58；海岛41 vs 49；灵签1619 vs 1888。
   - 虽然能活到 D7+，但前5日已经存在投入和成长偏弱信号。
   - 更像逐步失去投入，而不是突然断崖式退出。

## 最重要结论

### 1. D3-D4 是滚服玩家的特殊掉点
滚服不是整体高风险标签，但 D3-D4 明显聚集。滚服玩家有经验，理论上更熟悉前期节奏，因此这里应重点查：新服重复体验疲劳、成长性价比、榜单竞争、资源/礼包收益是否低于老玩家预期，而不是按普通新手流失解释。

### 2. D3-D4 滚服与非滚服是两种问题
- 滚服：相对“正常滚服玩家”成长效率明显落后，且出现减投、停止部分玩法后退出。
- 非滚服：战力和排名落后更突出，更像成长/竞争体验受挫。

### 3. D7+ 必须拆滚服与非滚服
- 滚服 D7+：前5日是高投入高成长，不应继续研究新手期；直接看 D5 后行为断点。
- 非滚服 D7+：前5日已经有较弱信号，可以作为提前预警人群。

## 后续分析优先级

- **P0：D7+ 滚服高强度流失（3人）**：看最后活跃日前1~3日行为变化，定位真正断点。
- **P1：D3-D4 滚服早退（6人）**：重点看最后1-2日充值停止、主线/海岛停止、榜单变化，以及与正常滚服玩家的差异。
- **P1：D3-D4 非滚服成长受挫（4人）**：重点查战力成长、资源获取、卡点、榜单压力。
- **P2：D7+ 非滚服渐进衰减（14人）**：可纳入提前预警模型。
- **P3：D1-D2 首充试水（10人）**：做整体首充后漏斗，不建议逐人重运营。

## 注意

当前名单跨不同创角日期，`未流失` 中包含较新的角色，存在观察期不足（右删失）问题。因此不能直接用“滚服已流失率 vs 非滚服已流失率”下因果结论；本次结论主要用于流失阶段和行为画像归类。
