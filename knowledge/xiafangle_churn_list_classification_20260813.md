# 下方了：流失名单归类分析（2026-08-13）

## 口径

- 样本：新增首日充值 >= 500 元角色，共 63 人；已流失 37 人、未流失 26 人。
- `是否滚服=是`：当前角色创建前，同一 `nb_open_id` 下已有创建时间更早的其他角色。它是玩家历史经验标签，不表示当前角色流失后迁服。
- D1-D4 流失玩家：与“同滚服状态、未流失玩家”比较到对应流失日。
- D7+ 流失玩家：与“同滚服状态、未流失玩家”比较前5日表现。
- SQL 日指标缺失会被输出为 0，因此成长/进度对比采用截至观察日的最后一个非0值，避免把“当天没有对应事件”误判为状态归零。
- 本知识文件不保存玩家 ID / 昵称明细，只保存聚合口径和标签规则。

## 综合早期强度

内部标签指标：

`综合早期强度 = median(同类战力比, 同类主线比, 同类海岛比, 同类高级灵签消耗比)`

其中“同类”指同滚服状态的未流失玩家，并使用相同观察窗口。

解释阈值：
- `< 65%`：明显偏弱。
- `约 80% ~ 115%`：接近正常。
- `>= 115%`：明显偏强。

该指标只用于本次名单内部分类，不替代现有大R流失风险模型。

## 名单内价值层级

仅用于本次 37 人名单的分析优先级，并非项目统一大R定义：

- 高价值：历史累计充值 >= P75 = 3239 元。
- 中价值：历史累计充值 >= 中位数 1110 元且 < 3239 元。
- 低价值：历史累计充值 < 1110 元。

## P0重点人群

本次规则共识别 P0 9 人，满足以下任一：

1. `高付费低转化中后期流失`；
2. `高强度投入后流失` 且为名单内高价值；
3. `滚服高投入早退`。

P0 的共同点不是“早期玩得差”，而是投入价值高，且当前前5日/早期指标无法充分解释退出，更适合逐人追最后活跃日前1~3日行为。

## 关键分析结论

### 1. D3-D4 滚服玩家必须拆成两类

原先把 D3-D4 滚服玩家统一解释为一类会过于粗糙。实际存在：

- `滚服高投入早退`：2人。投入较高、成长接近正常滚服玩家，但仍早退，更像新区冲榜回报、重复养成体验或预期落差问题。
- `滚服低成长早退`：4人。相对正常滚服玩家，本轮新区战力和玩法推进明显偏弱，且多人出现流失前停充，更像“有经验，但这轮新区没跑起来”。

### 2. D3-D4 非滚服更像成长/竞争受挫

4 人统一归为 `非滚服成长受挫早退`。这类主要表现为战力偏弱、推进不足，部分玩家战力排名明显恶化。重点排查 D2-D4 的资源缺口、战力卡点、榜单竞争和付费停止节点。

### 3. D7+ 不能继续只看“前5日强弱”

D7+ 分成四类：

- 高强度投入后流失：7人；
- 高付费低转化中后期流失：1人；
- 正常投入后流失：3人；
- 前期偏弱渐进流失：6人。

其中前三类前5日并没有统一的“早期体验失败”特征，必须接现有 `xiafangle_whale_churn_monitoring_20260804.yaml` 的最后活跃日前1~3日行为模型继续定位。

### 4. D1-D2 也要拆“低成长”与“正常成长仍退出”

- 低成长即退：6人，更适合查首充后30分钟/2小时、首次卡点、首日战力提升与资源获取。
- 短留存即退：4人，成长并不明显落后，更适合查首日目标感、完成主要玩法后的后续目标和退出前最后事件。

## 建议使用方式

最终名单建议保留以下字段：

- 主分类标签
- 辅助标签
- 分析优先级
- 同类累计充值比
- 同类战力比
- 同类主线比
- 同类海岛比
- 同类灵签比
- 战力排名变化
- 综合早期强度
- 核心判定
- 建议排查方向

这些标签为描述性分类，不应直接写成确定因果。尤其 D7+ 玩家，最终原因仍需要最后活跃日前1~3日的在线、玩法覆盖、PVP/BOSS/押镖、充值停止、成长停滞等行为证据补充。
