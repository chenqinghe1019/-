# 下方了：流失名单归类分析（2026-08-13）

## 口径修正

- `是否滚服=是` 表示：该角色创建时，玩家是从其他服务器滚服而来。
- 它不表示该角色流失后又去了其他服，因此不能把滚服玩家视为“假流失”或“迁服未流失”。
- `是否滚服` 仅作为玩家来源/历史经历特征，用于比较不同流失阶段的人群构成。

## 样本说明

- 本次样本共 63 人，其中已流失 37 人、未流失 26 人。
- 该名单为专项样本，不可把 37/63 直接解释为项目整体流失率。
- 本次仅同步聚合结论与归类方法，不保存玩家 ID / 昵称等名单明细。

## 归类建议

1. **D1-D2 首充试水快速流失**：前期充值集中在首日，成长和进度几乎未建立，优先做首充后行为漏斗分析。
2. **D3-D4 早期成长/竞争体验流失**：已经持续付费 2~4 天，也开始推进玩法，但成长速度和排名表现明显弱于未流失玩家；该组滚服玩家占比 60%，建议进一步拆滚服/非滚服比较。
3. **D7+ 中后期流失**：前5日付费和成长已经接近正常玩家，不能仅用前5日表现推断最终原因；应接最后活跃日前1~3日行为模型定位真正掉点。
4. **滚服标签**：作为上述每一类的二级标签，而不是独立流失类型。例如：`D3-D4早期流失-滚服`、`D7+中后期流失-非滚服`。

## 与现有流失预警模型的衔接

现有 `xiafangle_whale_churn_monitoring_20260804.yaml` 已明确：风险识别优先看最后活跃日前 1~3 日的玩法覆盖、PVP、合作试炼、在线时长、主线/海岛推进、战力增长、充值天数等。

本次名单只有前 5 日的战力、排名、高级灵签、主线、海岛和充值，因此适合用于“流失阶段和早期画像归类”，不适合对 D7+ 玩家直接推断最终流失原因。

## 运营优先级建议

- **P0：D7+ 高价值流失**。前5日已经形成较强投入和成长，应继续追最后活跃日前行为衰减。
- **P1：D3-D4 早期流失**。重点分析成长速度、排名恶化、付费停止点，并单独比较滚服与非滚服玩家。
- **P2：D1-D2 快速流失**。更适合作为首充后产品漏斗问题聚合分析，不建议逐个重运营。
