# 暴弹飞射：首日关卡破冰率口径（2026-08-27）

## 目标
观察新增玩家首日（D1）在不同主线关卡的首次付费/破冰表现。

## 项目与数据
- 用户表：`ta.v_user_42`
- 事件表：`ta.v_event_42`
- 主体：`#account_id`
- 新增日期：`create_role_time` Unix 秒转换后的日期
- 主线：`battle_type=1`
- 战斗事件：实际开始事件使用 `battle_star`，同时保留 `battle_result` 用于识别已有主线记录/跳关结算
- 付费：`$part_event='pay_log' AND payment>0`

## 破冰定义
- 破冰 = 玩家新增首日首次发生正向付费。
- 首次付费时间：玩家新增首日所有 `payment>0` 订单中的最早 `#event_time`。
- 破冰关卡：首次付费发生前，玩家最后一条主线 `battle_star`/`battle_result` 记录对应的 `map_id`。
- 若首付前没有任何主线记录，则归为 `map_id=0`（进入主线前）。

## 关卡破冰率
- 关卡到达人数：首日出现该主线关卡 `battle_star` 或 `battle_result` 的去重角色数。
- 到达时未破冰人数：首次到达该关卡时尚未发生首日首次付费的角色数；未付费玩家也计入。
- 该关卡破冰人数：破冰关卡归因到该 `map_id` 的首日首次付费角色数。
- 关卡破冰率 = 该关卡破冰人数 / 到达时未破冰人数。
- 该口径避免把已经在前序关卡完成破冰的玩家继续放进后续关卡分母，从而稀释后续关卡的真实破冰效率。

## 关卡付费率与 ARPPU（2026-08-27 新增）
- 每一笔新增首日 `payment>0` 的付费，按付费发生前最后一条主线 `battle_star`/`battle_result` 记录归因到对应 `map_id`。
- 同一玩家可在多个主线关卡发生付费，因此“关卡付费人数”按关卡内 `#account_id` 去重，不限定首次付费。
- 关卡付费金额 = 归因到该关卡的首日全部正向付费金额之和。
- 关卡付费率 = 关卡付费人数 / 关卡到达人数。
- 关卡 ARPPU = 关卡付费金额 / 关卡付费人数。
- 付费发生在任何主线记录之前的订单不归入具体关卡；如需观察可单独扩展为 `map_id=0`。

## 辅助指标
- 关卡到达率 = 关卡到达人数 / 新增人数。
- 首日整体破冰率 = 首日首次付费人数 / 新增人数。
- 累计破冰率 = 截止当前关卡的累计破冰人数 / 新增人数。

## 2026-08-24~08-26 vs 2026-07-17~07-22 初步观察
- 首日整体破冰率：`6.03%` vs `6.76%`，下降 `0.73pct`，相对约 `-10.8%`。
- 10003（1-3）仍是绝对核心破冰点：新周期该关破冰人数占首日破冰人数 `68.47%`，旧周期 `67.71%`，结构基本稳定。
- 10003 关卡破冰率由 `10.92%` 降至 `9.06%`，下降 `1.86pct`（相对约 `-17%`）。
- 新周期早期关卡到达更好：10001 到达率 `66.56%` vs `63.51%`；10002 `55.77%` vs `53.17%`；10003 `45.63%` vs `42.24%`；20001 `34.45%` vs `32.11%`。说明破冰下滑并非由主线前段到达不足导致。
- 到 10003 为止累计破冰率：`4.13%` vs `4.89%`，差 `-0.76pct`；最终整体差 `-0.73pct`。因此整体破冰下滑几乎全部在 1-3 及之前形成，后续关卡基本没有进一步扩大差距。
- 旧周期 10001/10002 尚有 21 名破冰玩家（累计约 `0.32%` 新增），新周期两关均为 0；若属于付费触点调整，需要单独确认是否为有意后移。
- 以新周期 10003 到达时未破冰人数 1534 计算，若仍保持旧周期 10.92% 的局部破冰率，理论约可产生 167~168 名破冰玩家，较实际 139 名多约 29 名；总首日破冰率理论可接近 `6.9%`。说明当前前段漏斗量级足够，核心问题更偏 1-3 商业化触发/商品吸引力，而不是玩家没有走到这里。
- 50004、60004 等后段局部破冰率虽高，但未破冰分母只有几十人，暂不宜作为核心结论。
