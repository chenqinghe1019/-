# 下方了：种族抽“平均多少抽产出1张”按等级内抽数统计口径（2026-08-26）

## 核心口径
- 指标必须在同一卡池等级内闭环计算，不跨等级累计抽数。
- 例如：Lv5 传说+ 平均多少抽产出1张 = 所有归属 Lv5 的种族抽事件顶层 `gacha_num` 之和 / Lv5 传说+英雄产出数量。
- Lv5 的分子只包含 Lv5 内的种族抽，不包含 Lv1~Lv4 的历史抽数，也不包含 Lv6 及之后的抽数。
- 各等级分别独立计算：LvN 平均多少抽产出1张 = LvN 种族抽总抽数 / LvN 对应类型英雄产出数量。

## 字段与分组
- 种族抽事件：`recruit_log`，`gacha_type=3`。
- 真实抽数使用 `recruit_log` 顶层事件属性 `gacha_num`，不是 `award_ting.gacha_num`。
- `gacha_num` 必须在拆 `award_ting` 前按事件级保留，避免一条事件因多个奖励元素被重复累计。
- 最终按 `pool_level` 分组后分别得到该等级的 `等级种族抽数`，再与该等级各英雄类型产出相除。

## 指标
- 人均产出数量 = 某等级某类型英雄产出数量 / 该等级发生过种族抽的去重玩家数。
- 平均多少抽产出1张 = 某等级种族抽总抽数 / 某等级某类型英雄产出数量。
- 等级内数量占比 = 某等级某类型英雄产出数量 / 某等级全部英雄产出数量。
