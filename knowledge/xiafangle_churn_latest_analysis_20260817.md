## 对“其他待查”的进一步人工观察

当前自动规则对“在线大幅下降但玩法覆盖数没有下降”较保守，导致部分明显活跃强度衰减仍落在其他待查。

典型：
- 轰趴有限公司：D-3 在线127分钟 -> D-1 32分钟，玩法覆盖仍3类，主线/海岛均无推进，排名稳定。
- 离曲：540分钟 -> 115分钟，玩法覆盖仍4类，排名1，成长仍强，更像活跃时长/投入强度快速下降。
- 云梦喵喵：247分钟 -> 105分钟，D0仅10.6分钟且玩法覆盖0，排名1，属于末期活跃快速收缩。
- 天师张角：129分钟 -> 71分钟，玩法覆盖仍4类，排名2->3，属于轻度活跃衰减叠加竞争位置下降。
- 苏沐雪：D-3~D-1均无在线，D0仅短暂回流16分钟；已停充17天，更像“回流尝试失败/间歇回流后再流失”，不适合普通连续流失模型。
- 天师Y599U：仍保持四类玩法、排名1、最后活跃日仍充值；虽在线较D-3下降，但D-1仍有133分钟，更接近“无明显先兆/高价值突发退出”。

## 建议调整后期规则

1. 增加“活跃强度衰减”：D-3在线>=60分钟，D-1较D-3下降>=50%，即使玩法覆盖不变，也作为活跃衰减候选；最好结合D-2趋势避免单日波动。
2. 增加“回流后再流失”：D-3~D-1连续无在线、D0短暂登录，且此前已停充较久。该类不要当正常连续流失。
3. “突发流失”应允许玩法覆盖、排名、充值仍正常但在线时长略下降；高价值且D-1仍保持较高在线时，可保留突发/外部因素候选。
4. D7+ 高价值玩家建议把“在线分钟趋势”升级为核心指标，而不是要求玩法覆盖同步下降。

## 当前分析重点

- P0：前期正常但 D7+ 流失的高价值玩家，优先看活跃强度变化、停充时间、最后行为与回流形态。
- P1：成长受挫/付费收益弱玩家，继续查付费后的战力转化、主线/海岛卡点和资源缺口。
- P1：竞争优势变弱玩家，继续查排名恶化前后战力差、充值变化以及同服头部玩家拉开速度。
