# 下方了：2026-08-24~08-26 vs 2026-07-17~07-24 付费结构对比

## 背景
对比两批新增玩家 D1~D3 的商品付费结构，重点观察两项调整：
1. 七日目标增加/调整小额礼包。
2. VIP2 礼包由 1 元调整为 3 元（旧：VIP礼包 special_1；新：VIP礼包 special_3）。

> 注意：新批次 2026-08-24~08-26 样本明显更小，尤其 D3 多个商品的付费人数占比统一出现 20%，D3 结论只能看方向，不适合下强因果结论；两批次不是严格 A/B，也可能受到流量结构、渠道质量等影响。

## 总体结构变化
- D1 新人特惠低/中价三档（6/12/30 元）付费金额占比：44.53% -> 61.63%，+17.10pct。
- D1 新人特惠 98 元档付费金额占比：14.08% -> 4.33%，-9.75pct；付费率 0.36% -> 0.06%。说明 D1 结构明显从高客单向低/中客单集中，高价付费后移。
- 由“单品付费率 / 单品付费人数占比”反推整体日付费率：D1 约 6.74% -> 6.00%，D2 约 15.42% -> 14.33%，整体付费转化没有提升。
- 由一次性礼包关系“总 ARPU ≈ 商品价格 × 单品付费率 / 单品付费金额占比”反推：D1 约 2.51 -> 1.35 元（约 -46%），D2 约 8.71 -> 5.79 元（约 -34%）。因此占比更集中不代表绝对流水更高，当前新批次整体付费强度偏弱。

## 七日目标小额礼包
旧批次七日目标主要为 12/30/12 元档；新批次扩展为 6/12/30/6/6 元等更低门槛组合。

### D1
- 付费金额占比合计：0.72% -> 1.06%，+47%。
- 单品付费率合计（未去重，仅用于观察商品渗透）：0.09% -> 0.18%，约翻倍。
- 按“价格 × 付费率”估算单模块每新增玩家收入贡献：约 0.0108 -> 0.0144 元，约 +33%。
结论：D1 小额礼包对降低首购门槛、扩展购买覆盖有效。

### D2
- 付费金额占比合计：1.97% -> 0.89%，约 -55%。
- 单品付费率合计：0.86% -> 0.86%，基本持平。
结论：低价化维持了购买覆盖，但由于客单下降，D2 流水贡献降低。

### D3
- 付费金额占比合计：4.89% -> 16.77%，明显上升。
- 但新批次 D3 样本很小，只能说明有较强的后续购买信号，暂不作为最终验证。

综合：七日目标小额礼包的价值更偏“拉购买人数/增加付费触点”，D1 已出现明确正向信号；是否能稳定提升前三日总流水，需要等新批次 D3 样本成熟后再确认。

## VIP2：1 元 -> 3 元
D1 对比（旧 special_1 vs 新 special_3）：
- 付费率：0.41% -> 0.06%，约 -85%。
- 付费人数占比：6.03% -> 0.99%，约 -84%。
- 付费金额占比：0.16% -> 0.13%，约 -19%。
- 按“价格 × 付费率”估算每新增玩家的该商品收入：1×0.41% = 0.0041 元 -> 3×0.06% = 0.0018 元，约 -56%。
- 旧 1 元档 D2/D3 仍有 0.29%/0.17% 的付费率，新 3 元档当前样本未见对应延迟购买。

结论：从当前数据看，VIP2 由 1 元提到 3 元没有带来收入提升，反而显著损伤低门槛转化；如果该礼包承担首次/早期付费破冰作用，3 元方案当前不成立。建议恢复 1 元或至少做 1/2/3 元分流验证。

## 当前判断
- 七日目标小额礼包：局部正向，主要提升付费触点和 D1 购买渗透，但不是所有日龄都提升流水。
- VIP2 1->3：明显负向，购买人数和收入代理指标均下降。
- 新批次整体：付费结构更集中在低/中价新人特惠，高价购买后移，但整体 D1/D2 付费率和 ARPU 仍低于旧批次。不能把总盘下降单独归因于 VIP2，98 元新人特惠、终身卡等高客单商品同步走弱也是重要因素。
