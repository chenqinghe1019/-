## 核心事件字段语义
- `pay_log.payment`：付费金额；`token_payment`：代币金额，源表说明“消耗代币数量*100”；同时有 `product_id/product_name/product_type/pay_result/order_id/payment_method/system/change_reason`。
- `in_out_log.change_reason`：登录/登出；`online_time`：登出时上报在线时长，单位秒。
- `money_log` / `item_log`：`change_type=1` 产出，`change_type=2` 消耗；`item_result` 是变化后结果；有 `item_id/item_name/item_type/item_num/item_quality/change_reason`。
- 基础 `battle_star`：`battle_uid/battle_type/map_id/battle_array`。
- 基础 `battle_result`：`battle_uid/battle_type/map_id/battle_array/battle_result/battlepoint_id/battle_time/battle_turn`；`battle_result` 说明为成功/失败/跳过/退出。
- `gacha_log`：`gacha_type/award_ting`；新版藏品扩展增加 `pool_type`。
- `hero_get_log`：`hero_id/hero_name/star/hero_num/hero_quality/hero_result/change_reason`；`hero_result` 表示本次获得后累计获得多少个本体。
- `hero_star_up_log`：`hero_id/hero_name/star_before/star_after/cost_item/cost_hero`。

## SQL 口径提醒
- 战斗开始必须优先使用 `battle_star`，不要写成 `battle_start`。
- 基础 `battle_result` 的结果字段是 `battle_result`；合作副本扩展另有 `result`。
- 基础 `battle_type` 在 Excel 标注为 varchar；合作副本扩展标注为 double，SQL 按线上真实类型使用 `try_cast` 更稳。
- 合作副本 `map_id` 有备注：需确认不同层关卡 ID 是否会重复。
- 付费是否包含代金券需按需求决定：RMB 用 `payment`，代币另看 `token_payment`。
