# 下方了项目表口径

更新时间：2026-07-06

- 下方了项目使用数数 41 项目表。
- 用户表：`ta.v_user_41`
- 事件表：`ta.v_event_41`
- 后续涉及下方了项目 SQL，默认不要使用 44，优先使用 41。
- `ta.v_user_41` 没有 `first_payment` 字段；首日付费分层必须使用注册当天 `pay_log.payment` 汇总。
- `pay_log.payment` 单位为分，统计金额和首日付费分层前必须 `/100` 转为元。
- 主线战斗开始事件为 `battle_star`，不是 `battle_start`；主线战斗用 `battle_type = 1`。
- 次日留存或流失判断可按次日是否存在 `in_out_log` 事件。
- 数数日期宏 `${PartDate:date}` 只能接裸字段写法，例如 `"$part_date"${PartDate:date}`；不能写成 `别名."$part_date"${PartDate:date}`，否则容易被宏展开成重复字段名并报错。
- 如需在子查询中筛选新增日期，先在内层生成字段名 `"$part_date"`，外层筛选时也使用裸字段 `"$part_date"${PartDate:date}`，不要加表别名。
