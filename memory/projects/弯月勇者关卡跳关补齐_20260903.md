# 弯月勇者关卡跳关补齐口径

- 项目表：ta.v_event_44 / ta.v_user_44。
- 主线关卡：battle_type = 20。
- 主线通关：battle_result = 1。
- 关卡漏斗统计中，为避免跳关造成中间关卡人数断层，以玩家在累计统计窗口内达到的最高主线 map_id 为进度上界。
- 有效关卡列表中低于最高 map_id 的中间关卡，即使没有真实 battle_result 记录，也补记为已挑战且已通关。
- 次数口径：真实有战斗记录的关卡保留真实挑战次数与通关次数；完全缺失的中间关卡补 1 次挑战 + 1 次通关；低层有挑战但无成功结算、而玩家已到达更高关卡时，该层通关次数至少补为 1。
- 该补齐逻辑用于累计关卡漏斗，避免将跳关误判为玩家在中间关卡流失。
- 新增日期汇总展示口径：GROUPING SETS 内部仍保持“汇总”占位，不在聚合层计算 min/max。仅在最外层展示时，把“汇总”替换为当前新增筛选范围的最小新增日期~最大新增日期，例如 2026-08-01~2026-08-07；不得改变原统计聚合逻辑。
- 失败玩家重复挑战率（2026-09-04修正）：不再依赖 raw battle_result 失败值，也不依赖 battle_star。直接沿用现有关卡漏斗已验证的挑战/通关次数口径：玩家该关 challenge_cnt > pass_cnt，则记为失败玩家；在失败玩家中 challenge_cnt >= 2，则记为重复挑战玩家。失败玩家重复挑战率 = 重复挑战玩家数 / 失败玩家数。该指标仅基于真实关卡记录聚合后的 challenge_cnt/pass_cnt 判断，不使用跳关补齐出来的虚拟挑战次数。
