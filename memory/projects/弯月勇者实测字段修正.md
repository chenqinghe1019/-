# 弯月勇者实测字段修正

更新时间：2026-08-31

## v_event_46 的 domain 字段

埋点 Excel 中 `domain` 被定义为公共事件属性，但 Trino 实测查询 `ta.v_event_46` 时，`pay_e."domain"` 报错：`Column 'pay_e.domain' cannot be resolved`。

因此弯月勇者 SQL 统一按以下规则处理：
- `ta.v_user_46`：可使用 `domain='release'` 作为正式服限制。
- `ta.v_event_46`：不要直接引用 `domain` 字段，避免列不存在报错。
- 事件表正式服范围通过先筛选 `v_user_46.domain='release'` 的角色 cohort，再按 `#account_id` 与事件表关联实现。

## 在线时长
- 事件：`in_out_log`
- 字段：`online_time`
- 单位：秒
- 登出时上报
- 玩家日在线时长：按 `#account_id + date(#event_time)` 汇总 `sum(online_time)`，再除以 60 转分钟。
