# 弯月勇者表后缀修正

> 2026-08-31 用户明确修正：弯月勇者实际表后缀为 44，不是 46。

## 当前唯一有效表口径
- 事件表：`ta.v_event_44`
- 用户表：`ta.v_user_44`
- 后续所有弯月勇者 SQL 优先使用后缀 44。
- 任何旧文档或旧 SQL 中出现的 `ta.v_event_46` / `ta.v_user_46` 均视为已废弃，应替换为 `ta.v_event_44` / `ta.v_user_44`。

## 已确认的在线口径
- 在线/活跃事件：`in_out_log`
- 在线时长字段：`online_time`
- `online_time` 单位：秒，统计时除以 60 转分钟。
- 当前实际 `ta.v_event_44` 不应默认筛 `domain`；正式服 cohort 通过 `ta.v_user_44.domain='release'` 控制。
- 当前线上 `ta.v_user_44.create_role_time` 实际查询类型为 `double` 时间戳；SQL 按 `from_unixtime(try_cast(create_role_time AS double))` 转换，不按 timestamp 直接 `date_format`。

## 战斗与关卡口径
- 战斗开始事件：`battle_star`（不是 `battle_start`）。
- 战斗结算事件：`battle_result`。
- 主线关卡：`battle_type = 20`。
- 主线通关：`battle_result = 1`。

## 关卡付费/LTV口径
- 爆弹 SQL 中的 `product_id = 20001` 是其他项目的月卡排除口径，不可直接套到弯月。
- 弯月商品配置统一优先从 `ta_dim.dim_44_0_vprop_sql_1439` 获取。
- 维表键：`product_concat`；商品显示名字段：`#vp@product_concat@product_name`；维表查询需限制 `"$part_event" = '$user'`。
- `product_concat` 口径为 `concat(product_type, cast(cast(product_id as bigint) as varchar), product_name)`。
- 当前线上 `pay_log.product_name` 实际类型可能为 `array(varchar)`，不得直接 `cast(product_name AS varchar)`；如需参与拼接维表 key，取 `element_at(product_name, 1)`。
- 弯月关卡 LTV 如需“剔除月卡”，应基于上述商品维表返回的商品显示名识别，商品名包含“月卡”则剔除；不要直接使用 pay_log.product_name 判断。
